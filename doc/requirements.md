# 《Ring Run》需求文档

## 1. Overview

一款约 35–55 秒的竖屏单笔路线喜剧：婚礼将在一分钟后开始，玩家从自己的头像戒指盒出发，在 4 秒内画一条连续安全路线，让婚戒依次穿过猫爪、扫地机器人和滚动香槟瓶抵达婚礼现场。

第二个空间手势样本验证“线是可通行道路”而非 Guard My Face 的“线是防御墙”：同样使用连续 Pointer、折线简化、路径碰撞和端点容错，但运动主体沿线前进，失败来自路线与动态威胁相交。

## 2. Visual Design

- 全屏 100vw × 100dvh，主验收 390×844，下限 320×568，无左右留白。
- 方向：1960 年代高级婚礼筹备图，奶油邀请函纸、深瓶绿、酒红、金箔和钴蓝；像有人在请柬背面紧急画路线。
- 当前玩家头像位于移动的深绿天鹅绒戒指盒正面，用户名写在金色 `RING BEARER` 签条上；身份是被威胁的运动主体，不是 HUD 装饰。
- 入口只显示场次、剩余墨水、一句危险句、起点、目标和 `DRAW ONE SAFE ROUTE`；不显示教程卡或复杂地图图例。
- 玩家路线为酒红色蜡笔线，绘制中有奶油高光；接受后变为金边深绿缎带道路。
- 三类威胁都使用可读的编辑插画造型；功能图标用同一套 2px SVG 线条，无 Emoji。

## 3. Game Mechanics

- 三幕共用同一状态：`briefing → drawing → locked → running → success/failure → final`。
- 场景 1 `THE CAT`：一只猫爪沿横向弧线每 1.6 秒扫过画面中部；戒指盒与猫爪距离小于 34px 时失败，末拍猫爪戴上婚戒。
- 场景 2 `THE VACUUM`：圆形扫地机器人沿矩形巡逻路线移动，速度 72px/s；距离小于双方半径和时失败，末拍机器人顶部亮起戒指。
- 场景 3 `THE CHAMPAGNE`：香槟瓶从右上沿斜坡滚向左下，1.9 秒后循环；碰撞后戒指套在瓶颈上。
- 绘制最多 4.0 秒，只允许一个 active pointer 和一条连续线；必须从起点 54px 范围内开始，并在目标 64px 范围内结束。
- 起点在 54px 内自动吸附到戒指盒；终点在 64px 内自动吸附到目标。路径最大长度为短边 2.65 倍，采样间距 6px。
- 松手后以 Ramer–Douglas–Peucker 简化到最多 48 点；长度不足 80px、未到目标或与静态禁区相交时，不消耗机会，给出具体修正提示。
- 接受后戒指盒沿折线弧长以 94–118px/s 前进（按视口高度取 `max(94, 14vh)`），转角处保持恒速；目标半径 30px。
- 动态威胁和戒指盒使用圆/胶囊距离检测，单帧 delta 钳制到 33ms；当前最高位移低于 4px，避免短屏高速穿透。
- 成功基础 100 分 + 剩余墨水比例 ×100 + 路线直接度 ×80；失败立即重画当前幕，不丢已完成幕。

## 4. Controls

- Pointer / Touch：在起点附近按下，连续拖动路线，松开后若满足约束立即开始运行。
- Canvas 使用 pointer capture，第二根手指忽略；pointercancel / lostpointercapture 安全回到 briefing，不遗留 drawing 状态。
- 结果主按钮使用 pointerdown；Canvas `touch-action:none`，按钮 `touch-action:manipulation`。
- 桌面鼠标与移动触屏使用同一 Pointer 代码；不依赖 hover。

## 5. Win / Lose Conditions

- 单幕胜利：戒指盒沿玩家路线到达目标，且未与当前动态威胁碰撞。
- 单幕失败：戒指盒与猫爪、扫地机器人或香槟瓶碰撞；精确接触冻结 180ms，再演出对应荒诞归属：`THE CAT SAID YES / THE VACUUM IS ENGAGED / THE BOTTLE SAID YES`。
- 全局胜利：连续通过三幕；最终展示玩家头像、总分、最短路线和 `THE WEDDING CAN START`。
- 失败只重试当前幕；不设置生命数或广告式倒计时。

## 6. Sound Effects

- 起笔：560Hz 三角波 45ms；路线采样每 100ms 最多触发 700–900Hz 轻擦声。
- 起点/终点吸附：420→690Hz 正弦上滑 80ms；无效终点：180→120Hz 方波 110ms。
- 路线锁定：220/330/495Hz 三音叠合 140ms，像金属盒扣。
- 戒指盒沿线：每经过 16% 路程触发 520–780Hz 轻木琴声，最大并发 1。
- 猫爪/机器人/香槟碰撞分别使用 180Hz 软拍、96Hz 电机骤停、140Hz 玻璃共振；音量 ≤0.06。
- 成功：523/659/784Hz 三音，各 80ms；全局成功增加 988Hz 末音。
